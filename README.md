# Wanderly — Trip Planner

A trip planning app for organizing days and places on a visual board.

![React](https://img.shields.io/badge/React-19-blue) ![Vite](https://img.shields.io/badge/Vite-8-purple)

## Features

- Add and delete days on a trip board
- Add places to each day with a name, category, notes, and time
- Edit day headers and place cards inline
- Horizontal scrolling board layout

## Tech Stack

- React 19
- Vite
- Plain CSS
- Font Awesome (icons)

## Concepts Practiced

- Component composition and prop drilling
- Lifting state up to a shared parent
- Immutable state updates with the spread operator and array methods
- Separating global app state from local UI state

## Getting Started

```bash
npm install
npm run dev
```
